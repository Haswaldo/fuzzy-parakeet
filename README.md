# Kirstie Grundy — Creative Portfolio

Static site (no build step). GSAP + ScrollTrigger + Lenis smooth scroll, all vendored locally.

```bash
python3 -m http.server 8000   # then open http://localhost:8000
```

- `index.html` — content & structure
- `css/style.css` — design tokens, layout, effects
- `js/main.js` — smooth scroll, pinned horizontal gallery, stacking cards, parallax, lightbox, cursor
- `js/fx.js` — WebGL ambient background, particles/confetti, section HUD, scroll-scrubbed Netflix ribbon, glitch, magnetic UI
- `assets/img` — images extracted from the original Canva PDF
